# DarkRAR — Arabic Archive Manager for Windows

A fast Arabic-first (RTL) archive manager for Windows with a modern dark interface. Open, extract, and create ZIP, 7Z, RAR, TAR, GZ, BZ2, XZ, ISO, BIN, and PKG/XAR archives. Includes settings, About dialog, context menu integration, and an installer that asks for install path, language, and theme.

**Version:** 1.0.0  
**Author:** LAETH KHARUDDIN  
**Copyright:** © 2026 LAETH KHARUDDIN. All rights reserved.  
**Language:** Arabic (default) / English  
**Theme:** Dark / Light  
**Platform:** Windows 10 / 11 (64-bit, AMD64 / Intel 64-bit)

---

## 📥 Download

Download the installer directly:

**https://archive.org/download/dark-rar-setup/DarkRAR-Setup.exe**

Run `DarkRAR-Setup.exe`, choose your install folder, language (Arabic/English), and theme (Dark/Light), then click **Install**.

---

## ✨ Features

- Arabic-first RTL interface, switchable to English from Settings.
- Dark theme by default with an optional Light theme applied instantly.
- Browse archive contents with sortable columns and instant search.
- Extract selected items or everything, with progress bar and cancel.
- Create ZIP / 7Z / TAR archives; add and delete items in writable archives.
- Test archive integrity.
- Password support with retry on wrong password.
- Drag and drop: drop an archive to open it, drop files into an open archive to add them.
- Navigate history (Back / Forward) and open files directly from inside archives.
- Context menu integration: **Open with DarkRAR** and **Extract here with DarkRAR** (no administrator rights required).
- About dialog showing version, author, and copyright.
- Settings dialog to change language and theme; saved in `%APPDATA%\DarkRAR\settings.json`.
- Installer asks for install location, language, and theme before installing.
- Clean uninstall via Windows Settings (Apps & features).

## ⌨️ Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+O` | Open archive |
| `Ctrl+N` | Create archive |
| `Ctrl+Shift+A` | Add files |
| `Ctrl+E` | Extract |

| `Ctrl+,` | Settings |

# DarkRAR — مدير الأرشيفات العربي

تطبيق سطح مكتب عربي (RTL) لإدارة الأرشيفات على ويندوز، بواجهة داكنة حديثة، يدعم فتح واستعراض واستخراج وإنشاء العديد من صيغ الأرشيف دون الحاجة لأي برامج إضافية.

**النسخة:** 1.0.0  
**المؤلف:** LAETH KHARUDDIN  
**حقوق النشر:** © 2026 LAETH KHARUDDIN. جميع الحقوق محفوظة.  
**اللغة:** العربية (افتراضي) / الإنجليزية  
**الثيم:** داكن / فاتح  
**النظام:** ويندوز 10 / 11 (64 بت، AMD64 / إنتل 64-bit)

---

## 📥 التحميل

يمكنك تحميل المثبّت المباشر من الرابط التالي:

> **https://archive.org/download/dark-rar-setup/DarkRAR-Setup.exe**

بعد التحميل، شغّل ملف `DarkRAR-Setup.exe` واختر مجلد التثبيت واللغة (العربية/الإنجليزية) والثيم (داكن/فاتح)، ثم اضغط **تثبيت**.

---

## ✨ المزايا

- واجهة عربية RTL افتراضية مع إمكانية التبديل إلى الإنجليزية من الإعدادات.
- ثيم داكن افتراضي مع ثيم فاتح اختياري يُطبَّق فورًا دون إعادة تشغيل.
- استعراض محتويات الأرشيف مع ترتيب وأعمدة قابلة للفرز وبحث فوري.
- استخراج المحدد أو الكل مع شريط تقدم وإلغاء العملية.
- إنشاء أرشيفات ZIP / 7Z / TAR وإضافة وحذف العناصر من الأرشيفات القابلة للكتابة.
- اختبار سلامة الأرشيف.
- دعم كلمات المرور مع إعادة المحاولة عند كلمة مرور خاطئة.
- سحب وإفلات: إفلات أرشيف لفتحه، وإفلات ملفات داخل أرشيف مفتوح لإضافتها.
- سجل تنقّل (رجوع/تقدم) وفتح الملفات مباشرة من داخل الأرشيف.
- تكامل مع قائمة النقر بزر الفأرة الأيمن: **فتح باستخدام DarkRAR** و **استخراج هنا باستخدام DarkRAR** (بدون صلاحيات مسؤول).
- نافذة **حول** تعرض الإصدار والمؤلف وحقوق النشر.
- نافذة **إعدادات** لتغيير اللغة والثيم، وتُحفظ في `%APPDATA%\DarkRAR\settings.json`.
- المثبّت يسأل عن مسار التثبيت واللغة والثيم قبل البدء.
- إزالة نظيفة عبر إعدادات ويندوز (التطبيقات والمزايا).
